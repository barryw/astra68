# Security policy

Astra 68 is pre-release hardware and operating-system software. It must not be
used to protect sensitive data or operate safety-critical systems.

Please report a vulnerability through GitHub's private vulnerability reporting
for this repository. Include the affected revision, target, reproduction steps,
impact, and any relevant traces. Do not open a public issue for an unpatched
security problem.

There are no supported release branches yet. Security fixes are applied to the
active `main` branch and documented with the affected architectural invariant
and regression test.
